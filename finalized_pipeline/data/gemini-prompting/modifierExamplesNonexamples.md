# Instructions on what to classify under each category of hedge
- subtitles indicate the category (and other forms in which it appears). Each list within the category show examples and non-examples of how the word is used or is not used as a modifier of degree. 
## 十分（じゅうぶん）
- Example: 十分に理解している（＝完全に、しっかりと）
- Example: 十分満足だ（＝満ち足りている）
- Example: 十分な準備をした（＝「十分な＋名詞」で「適切な量の」）
- Non-example: テンプレートだけで十分だ（＝それで足りる、それ以上いらない）

## 多少（たしょう）
- Example: 多少の誤差はある（＝いくらかの、名詞的用法「多少の＋名詞」）
- Example: 多少疲れた（＝少し）
- Example: 多少、表現などが似ていたかもしれない（）
- Example: 給料が多少上がった（＝わずかに、変化の度合い）
- Non-example: 多少にかかわらず（=多いか少ないかに関係なく）

## 大変（たいへん）
- Example: 大変お世話になりました（＝非常に、丁寧な強調）
- Non-example: 本当に大変でした（＝苦労した、困難だった）
- Non-example: 大変なことになった（＝深刻な事態、「大変な＋こと」）

## 少し（すこし）
- Example: 少し待ってください（＝しばらく）
- Example: 少し値上がりした（＝わずかに）
- Non-example: 少しも気にしない（＝「少しも＋否定」で「全く～ない」）

## 少しも（すこしも）
- Example: 少しも気にしない（＝「少しも＋否定」で「全く～ない」）
- Non-example: 少し気にしている（＝わずかに）

## 相当（そうとう）
- Non-example: 10万円ほどに相当する（＝値する、動詞「相当する」）
- Exampe: 相当苦労した（＝かなり、副詞）
- Example: 相当な実力の持ち主だ（＝かなりの程度の、「相当な＋名詞」）

## 結構（けっこう）[explanation and whether it is a hedge]
- Example: 結構難しい（＝かなり、程度副詞）
- Non-example: お茶はもう結構です（＝十分なので不要、丁寧な断り）
- Non-example: とても結構なお品ですね（＝素晴らしい、褒め言葉）
- Non-example: 大雨の中でもけっこうする（＝「けっこう」だが漢字が違い「予定通り実行する」の意。紛らわしいので注意）

## 若干（じゃっかん）
- Non-example: 若干名を募集する（＝少々な人数）
- Example: 若干不安が残る（＝少し）
- Example: 若干の修正が必要だ（＝少々）

## 非常に（ひじょうに）
- Example: 非常に重要だ（＝とても、フォーマルな場面）
- Example: 非常に危険な状況（＝極めて）
- Non-Example: 非常に備える（＝緊急事態）

## 割と（わりと）
- Example: 割と簡単だった（＝思ったより、予想との比較）
- Example: 割と気に入っている（＝そこそこ、控えめな肯定）
- Non-example: 満席率は９割と、非常に混んでいる（＝割合が9割であるという数値を示す）

## やや
- Example: やや値上がりした（＝少し、微妙な変化）
- Example: やや大きめのサイズ（＝若干）
- Non-example: ややこしい話だ（＝複雑だ。副詞「やや」とは語源が異なる形容詞）

## とても
- Example: とても嬉しい（＝非常に、素直な肯定）
- Non-example: とても信じられない（＝「とても＋否定」で「到底～ない」という慣用的な否定強調構文）

## とっても
- Example: とっても可愛い（＝「とても」のくだけた強調表現）
- Non-example: 私にとっても大事だよ。（）
- Non-example: とっても！（＝一語での感嘆表現。何かを修飾しているわけではなく間投詞的用法）

）
## 頗る（すこぶる）
- 頗る快調だ（＝非常に、やや古風・文語的）
- 頗る評判がいい（＝とても、フォーマルな響き）

## 甚だ（はなはだ）
- 甚だ遺憾である（＝非常に、公式な謝罪・声明の定型表現）
- 甚だ疑問だ（＝大いに、強い疑い）

## 誠に（まことに）
- 誠に申し訳ございません（＝本当に、フォーマルな謝罪）
- 誠にありがとうございます（＝心から、フォーマルな感謝）

## 大いに（おおいに）
- 大いに賛成だ（＝強く、明確な同意）
- 大いに楽しんだ（＝十分に、満喫した）

## ほぼ
- ほぼ完成した（＝もう少しで、完了間近）
- ほぼ全員が参加した（＝大部分）

## いくらか
## わずか

## 概ね（おおむね）
- 概ね順調だ（＝大体、全体的な評価）
- 概ね同意見です（＝おおよそ）

## ほとんど（殆ど／殆んど）
- ほとんど終わった（＝大部分）
- ほとんど食べない（＝「ほとんど＋否定」で「めったに～ない」）

## ほんの
- ほんの少しだけ（＝ごくわずかな、小ささの強調）
- ほんの気持ちです（＝ささやかな、贈り物を謙遜して渡す際の定型表現）

## そこそこ
- そこそこ美味しい（＝まあまあ、控えめな肯定）
- 30人そこそこ集まった（＝前後、「数字＋そこそこ」で「およそ」）

## まあまあ
- まあまあの出来だ（＝悪くない、可もなく不可もなく）
- まあまあ、落ち着いて（＝相手をなだめる間投詞的用法。程度副詞とは別機能）

## そんなに
- そんなに怒らないで（＝「そんなに＋否定・命令」でその程度まで～するな）
- そんなに難しくない（＝それほど、否定と共に）

## そう（～ない）
- そう簡単にはいかない（＝それほど簡単には、否定と共に）
- （紛らわしい別用法）そう思わない？（＝指示語としての「そう」。程度副詞ではなく代名詞的用法）

## 大して（たいして）
- 大して問題ではない（＝「大して＋否定」でそれほど重要ではない）
- 大して変わらない（＝それほど）

## それほど
- それほど難しくない（＝「それほど＋否定」）
- それほどでもない（＝褒められた際の謙遜の定型句「大したことはない」）

## まずまず
- まずまずの成績だった（＝まあまあ、そこそこ良い結果）
- 「調子はどう」「まずまずですね」（＝挨拶的な返答としての「そこそこ」）

## ぼちぼち
- 「調子はどう？」「ぼちぼちです」（＝そこそこ、関西発祥のくだけた返答）
- ぼちぼち始めようか（＝そろそろ、少しずつ・そろそろの意）

## めっちゃ／めちゃ
- めっちゃ美味しい（＝超、くだけたスラング）
- めちゃ怒られた（＝ひどく、程度の強調）

## 超／チョー／ちょー
- 超うれしい（＝とても、スラング的強調接頭辞）
- チョーむかつく（＝非常に、カタカナ表記で若者言葉のニュアンス）

## まじ／マジ
- マジで！？（＝本当に！？、驚きを表す間投詞的用法）
- まじ疲れた（＝本当に、形容詞の前で副詞的に）
- マジな話（＝真剣な、「マジな＋名詞」）

## 無茶苦茶（むちゃくちゃ）
- 無茶苦茶忙しい（＝非常に、程度副詞）
- 部屋が無茶苦茶だ（＝めちゃめちゃ、散らかっている・元々の意味「滅茶苦茶」）

## ひどく
- ひどく落ち込んでいる（＝非常に、程度）
- ひどく扱われた（＝残酷に、元々の意味「乱暴に」）

## 鬼
- 鬼忙しい（＝超、スラング的強調接頭辞）
- 鬼のような形相（＝文字通り「鬼」、本来の意味）

## クソ
- クソ寒い（＝ものすごく、下品なスラング強調）
- クソが！（＝怒りを表す間投詞、本来の下品な意味での使用）


## ちょっと
- Example: ちょっと高いですね（＝いくらか、控えめな程度を表す）
- Non-example: 今日はちょっと…（＝婉曲的な断りを表す語用論的用法で、程度を表していない）
- Non-example: ちょっとしたプレゼントです（＝「ちょっとした＋名詞」で連体修飾）

## それなり
- Example: それなりに頑張った（＝自分の範囲・力なりに、副詞的用法）
- Non-example: それなりの理由がある（＝「それなりの＋名詞」で連体修飾）
- Non-example: 分量はそれなりになる（＝「なる」の補語としての名詞的用法）

## すごく
- Example: すごく美味しい（＝とても、口語的）
- Non-example: すごく！（＝一語での感嘆表現。間投詞的用法で何も修飾していない）

## 随分（ずいぶん）
- Example: 随分と変わったね（＝かなり、驚きを伴う変化）
- Non-example: 随分な言い方だね（＝ひどい・失礼な、「随分な＋名詞」でネガティブな評価的用法）

## かなり
- Example: かなり難しい（＝相当、程度副詞）
- Non-example: かなりの人数が集まった（＝「かなりの＋名詞」で連体修飾的用法）

## いささか
- Example: いささか疑問が残る（＝少し、控えめな不満・懸念）
- Non-example: いささかも動じない（＝「いささかも＋否定」の呼応表現で全否定を強調）

## ある程度（あるていど）
- Example: ある程度は理解できる（＝一定の範囲で）
- Non-example: ある程度の覚悟が必要だ（＝「ある程度の＋名詞」で連体修飾）

## あまり
- Example: あまり好きではない（＝「あまり＋否定」で「それほど～ない」という程度の低さを表す）
- Non-example: あまりにも突然で驚いたので声も出なかった（＝あまりに(も)＋形容詞で「過度に」を表す接続的用法）
- Non-example: 心配のあまり眠れなかった（＝「名詞＋のあまり」で名詞化した用法）

## やたら
- Example: やたら忙しい（＝過度に、否定的なニュアンスを伴う程度副詞）
- Non-example: やたらと人に話しかける（＝様態副詞、無差別に・むやみにという行動の仕方を表す）

## ちょっぴり
- Example: ちょっぴり寂しい（＝ほんの少し、控えめな程度を表す）
- Non-example: ちょっぴりの勇気があれば大丈夫（＝「ちょっぴりの＋名詞」で連体修飾）
